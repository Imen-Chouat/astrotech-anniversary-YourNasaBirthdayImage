# 🚀 NASA Birthday App

## 🎨 For the Designer
- Export the story background at **1080 x 1920 px**.
- Save it as `club-background.png` inside the `public/` folder.

## 👨‍💻 For the Developer
1. Clone this repository.
2. Run `npm install`
3. Create a `.env` file and add `VITE_NASA_API_KEY=your_key`
4. Run `npm run dev` to start working!
